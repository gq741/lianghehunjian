量禾混剪 2026.11.05 排片修复更新

这是程序更新包，不是首次安装包。沿用原软件的 Python、模型和 FFmpeg。
支持已发布 10.24、MiniMax 10.29、11.04，以及已知 11.05 WorkBuddy 源码同步版本。
此次同时处理旧版说明文件/清单不同导致的更新不匹配；程序代码仍逐文件校验，未知改版不覆盖。

1. 保存工作，结束任务并退出量禾混剪。
2. 将整个 ZIP 解压到新的文件夹，不要覆盖旧软件，也不要只运行压缩包里的文件。
3. 双击“更新量禾混剪.cmd”。自动查找桌面快捷方式；找不到时选择旧软件 EXE 所在文件夹。
4. 等待自动备份、替换和免费自检。成功后使用原快捷方式重新打开软件。
5. 找到原来失败的成片任务，点击一次“重试”。不要重新生成文案、切换音色或清理缓存。
   未改文案/服务且成功缓存完整时复用整条音频与分析；界面仍需确认本次任务。
   若提示新增收费步骤，请先核对，不需要为了安装更新调用任何模型。

修复：排片失败时增加全局回溯重新分配，而非只尝试几种贪心顺序；
保持最多额外复用2次、同源范围最多2次、画面最低0.85倍、整条配音原速。
时间线分别显示“口播时长”和“已配净画面”，分组编号一致。
仍有缺口时，普通任务日志自动附加纯数字排片复现数据（小规模案例），不含文案、文件路径或密钥。
没有凭空填充无关画面；真实相关素材不够的案例仍会提示调整。

API Key、设置、任务、音乐、素材和已付费音频缓存不移动、不覆盖。
只更新程序，安装不调用收费模型。更新失败自动恢复；回退可运行“回退上次更新.cmd”。
备份在原安装目录 .lianghe-updates；结果在 update-result.json。保留备份，不要手动删除。
